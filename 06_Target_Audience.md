# Target audience and messaging

## Priority groups
**Civil engineers:** stage quantities, recognisable structural components, estimation workflows, model review.

**Architects / architectural designers:** move from SketchUp geometry toward clearer construction-stage models and takeoffs.

**Contractors / estimators:** readable quantities, Required Works, pricing assumptions and BOQ PDF output for review.

**Small AEC studios:** consistent presentation and working processes across projects.

**SketchUp users learning construction modelling:** short educational demos, practical scenarios, friendly terminology.

## Messaging by audience
- Engineers: "Build construction elements. Keep quantities connected."
- Architects: "Move beyond visual geometry."
- Contractors: "See the work items behind the model."
- Estimators: "A clearer path from model to BOQ."
- Learners: "Understand the stage. Model it. Review the quantity."

## Geographical context
India-first examples are welcomed; use simple Indian construction terminology where relevant. Display measurement/rate units accurately; never fabricate real prices, code sections, standards compliance or professional endorsements.

## Content goals
Awareness -> product understanding -> short proof/demo -> tutorial confidence -> visit **Bdesignertool.com**. Avoid conflating this with **BDesigner.online** project acquisition.
