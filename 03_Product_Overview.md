# Product overview — what to explain in a video

**BDESIGNER** is a construction-oriented SketchUp plugin designed for stage-based modelling and model-derived quantity/BOQ workflows.

## Publicly approved workflow
**MODEL -> REQUIRED WORKS -> PRICING -> QUANTITIES -> BOQ -> PDF EXPORT**

Meaning in plain English:
- **Model:** create or manage recognizable construction elements in SketchUp.
- **Required Works:** associate stage-relevant construction work items for estimation.
- **Pricing:** connect quantities to a material/stage rate library.
- **Quantities:** derive amounts from construction elements; user must review.
- **BOQ:** organize quantities and related items into a bill of quantities.
- **PDF Export:** generate a shareable BOQ PDF.

## Approved video-ready feature vocabulary
- Stage-based construction modelling
- Native SketchUp inference/snapping
- Live preview
- Edit existing placed elements
- Metric and Imperial measurements
- Model-linked quantities
- Required Works
- Rate Library
- BOQ / BOQ PDF Export
- Automatic visual materials
- Light and dark tool interface
- Reinforcement-related controls for applicable stages (show only with verified footage)

## Product proof: what visuals to record
1. Real SketchUp viewport and model before/after.
2. BDESIGNER stage selector.
3. A confirmed working stage's minimal inputs + preview.
4. Placement/snapping or editing a real component.
5. Quantity output and BOQ view.
6. BOQ PDF export interface and final readable output.

## Do not claim
- Automatically builds a complete building from a floor plan.
- Supplies certified structural engineering / mandatory code validation.
- Guarantees quantities/rates without review.
- Includes full production MEP or interior design systems.
- Ships features not confirmed by latest release.
