# Construction stages — publicly understandable explanations

These are **approved product-scope topics**. Individual stage availability must be verified against the actual product build before a "now available" video.

## Foundation / earthwork
| Stage | Simple explanation | Useful footage |
|---|---|---|
| Site Clearance | Model site preparation areas and related work quantities | Selected area, stage input, quantity card |
| Excavation | Define excavation volumes and related earthwork | Excavation geometry, dimensions, quantity |
| Footing | Model foundational footing elements | Footing preview, placement, model close-up |
| SSM Walls | Draw foundation-level stone/masonry walls | Wall path/snapping and final wall |

## Additional construction topics
- **Walls / Parapet Wall / Compound Wall:** distinguish each category; show actual supported controls only if verified.
- **Plaster / Putty / Paint / Skirting:** construction-finish work topics; use "in development" or concept treatment unless verified.
- **Stair railing:** glass/metal demonstrations only if current build visibly supports them.
- **MEP — Beta:** practical quantity/BOQ-oriented beta positioning, not full detailed engineering.
- **Finishing — Beta:** quantity/BOQ-oriented beta positioning, not complete turnkey detailed interiors.

## Stage-storytelling format
For any stage: context -> choose stage -> show 2–3 relevant inputs -> live preview -> place/edit -> practical resulting quantity -> clear outcome.

## Caution for construction representation
Real on-site construction sequencing varies by project. Do not imply every job requires all stages or that a demo replaces professional design, supervision or applicable local code checks.
