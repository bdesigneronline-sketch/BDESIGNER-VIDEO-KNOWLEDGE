# Scene scripting and output standards

## Default workflow
1. Ask what type of video only if unclear: teaser / product demo / tutorial / feature explain / update.
2. Choose duration (15, 30 or 45 sec promo; tutorials per actual steps).
3. Define ONE primary claim and audience.
4. Generate hook, core benefit, real proof and call-to-action.
5. Verify every visible product shot and wording; label missing footage.
6. Create the scene-by-scene production table.
7. Create **individual** screen-image prompts, animation prompts and audio cues.
8. Assemble review checklist.

## Mandatory storyboard columns
Scene number | time window | footage/asset | concise headline | small subtitle | voiceover | model/UI movement | transition | SFX | validation note.

## Copy rules
- Short top-left label; small top-right counter.
- Headline often 2–6 words.
- Bottom subtitle short (ideally around one short clause).
- Short sentences; do not cram technical explanations into each frame.
- Use only 1 main product idea in each scene.
- Explain technical terms simply at first mention (BOQ = bill of quantities when needed).

## Suggested 30-second architecture
- 00–03: hook / geometry alone is not enough.
- 03–09: construction-stage model and snap/placement proof.
- 09–15: show model quantities and Required Works.
- 15–22: rate/BOQ relation and export proof.
- 22–27: key benefit montage.
- 27–30: logo, tagline, website CTA.

## Prompt separation
**Screen prompt:** single static frame, exact layout, palette, typography, accurate model geometry/brand elements, no animation.

**Animation prompt:** duration, start/end frame guidance, moving layers, easing, camera path, transitions, SFX synchronization; preserve geometry and text.

**Voice/audio prompt:** script, speaking style, music and SFX with timing.

## Claims checklist
Check spelling and status; real footage; actual UI matches version; price/offer confirmed; CTA valid; no exaggerated structural/code/accuracy claims.
