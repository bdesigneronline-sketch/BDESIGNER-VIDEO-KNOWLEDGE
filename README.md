# BDESIGNER Tool — Video Knowledge Base

**Purpose:** A non-code knowledge base for Claude, ChatGPT and creative production tools to plan promotional, tutorial, feature-explanation and release videos for **Bdesigner Tool** at **Bdesignertool.com**.

**Scope:** Product concepts, approved public messaging, high-level construction workflows, visual identity, storyboards, screen prompts, voiceover, sound design, and production guidelines. **Never include plugin source code, Ruby scripts, private implementation, security architecture, credentials, client data, or unapproved screenshots.**

**Last curated:** 2026-10-22. The files are editorial references, **not evidence that every feature has shipped**. Confirm current version, UI and availability before publication.

## Quick start for a video agent
1. Read `CLAUDE.md` and `01_Brand_Identity.md`.
2. Read `03_Product_Overview.md`, `04_Construction_Stages.md`, and `05_Features_and_Benefits.md`.
3. Read the production rules: `07_Video_Design_Style.md` to `10_Video_Script_Guidelines.md`.
4. Select one topic from `11_Marketing_Video_Ideas.md` or `12_Tutorial_Video_Ideas.md`.
5. Make a concise script, storyboard and separate image/animation/audio prompts. Verify factual footage against actual plugin recordings.
6. Record release-specific changes in `14_Product_Updates.md`.

## Product vs services
- **Bdesignertool.com:** SketchUp construction modelling and quantity/BOQ plugin; **this repository is for its videos**.
- **BDesigner.online:** Separate architectural and construction services business. Do not mix service-company offers into Tool promotions unless explicitly requested.

## Source priority
1. Latest verified screenshots and product release confirmation supplied by the owner.
2. Explicitly approved marketing/product facts in this knowledge base.
3. Latest approved commercial website specification.
4. Older notes or exploratory ideas (never present as launched).

## Current output conventions
- Default social aspect ratio: 9:16 (vertical). Adapt to 16:9 only if requested.
- Premium motion-graphics video, not a slideshow.
- Keep on-screen text short and brand-consistent.
- Real plugin footage for software/functionality proof; concept renders must be labelled as concepts where necessary.
