# Approved features and honest benefits

| Feature/topic | Explain simply | Suggested visual |
|---|---|---|
| Stage-based workflow | Construction elements are organized by work stage | Stage nav and project model |
| Place / snap | Place parts using SketchUp modelling context | Cursor and inference close-up |
| Live preview | Review proposed geometry before placement | Preview alongside model |
| Existing element edit | Revisit a modelled stage and adjust values | Before/after edit |
| Metric / Imperial | Work with the project's units | Same input displayed in relevant units |
| Model-derived quantities | Quantities relate to what is modelled | Geometry -> quantity panel |
| Required Works | Include applicable work items for a stage | Work toggles and result |
| Pricing library | Link work/material assumptions to rates | Rate library illustration or UI |
| BOQ | Assemble organized quantity items | BOQ table screenshot |
| BOQ PDF Export | Export the document for review/share | On-screen export and sample PDF |
| Reinforcement display | Show/hide reinforcement visuals where supported | Verified viewport toggle |
| Light/dark themes | Choose comfortable tool panel contrast | Matching UI cut or split screen |

## Benefit phrasing
Use "helps connect", "designed to simplify", "supports", "makes it easier to review", "brings modelling and quantities together". Do not quantify savings without validated benchmark data.

## Feature proof priority
Use screen capture over speculative 3D UI mockups. For pre-release ideas, label the shot **Concept / Planned / Beta** as appropriate.

## Public exclusions
Do not list Client Package, Execution, Commercial Costing or Construction Timeline as product functionality.
